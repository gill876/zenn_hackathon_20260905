AsobiAgent (アソビ・エージェント)

LINEグループの中で「出発駅の確認」➔「公平な集合駅（駅すぱあと）」➔「実在のお店から投票」➔「予約の準備」までを進める、幹事いらずのマルチエージェント。

🚇 駅すぱあと MCP

ダイヤ情報不使用。範囲探索1回で、全員の平均所要時間を取得

💬 LINE Flex Message

アプリ不要。参加・確認・投票はボタンを押すだけ

⚡ GMI Cloud (Gemini 3.5 Flash-Lite)

日時・希望の読み取りとお店選び。止まってもルールで動き続ける

🗣️ 発表用の最初の一言（カンペ）

「こんにちは！私たちは、LINEグループのお出かけ計画を幹事なしで決められる『AsobiAgent』を開発しました。」

"Konnichiwa! Watashitachi wa, LINE group no odekake keikaku wo kanji nashi de kimerareru 'AsobiAgent' wo kaihatsu shimashita."

現場起点の切実な課題

東京の休日お出かけは、「幹事疲れ」と「人混み」の連続

😫 30往復以上のLINE調整

「誰がどこから来るか」「何時に集まるか」の調整だけでLINEが埋まり、誰も幹事をやりたがらない。

⚖️ 移動格差の不満

「自分だけ片道1時間かかる」「乗換が多すぎる」といった不満が生まれ、集まる場所の合意形成が困難。

☕ 週末東京の深刻な大混雑

渋谷・新宿の主要駅周辺はどこも満席。45分以上の行列に並び、落ち着いて会話すらできない。

🗣️ 発表用スクリプト

「友達とご飯に行こうとすると、LINEで何十通もやり取りし、移動時間の不公平さで揉め、結局渋谷の混雑した店で行列に並ぶことになります。AsobiAgentはこの負担をゼロにします。」

複数ステップの自律実行

4つのエージェントがLINEグループの中で連携

Agent 1

📅 出発駅・日時の読み取り

呼ばれてから参加した人のメッセージだけを読む。駅名は駅すぱあとの駅データで確認し、日時と希望はLLMで抽出。

Agent 2 (駅すぱあと)

🚇 公平な集合駅

範囲探索1回で、全員が行ける駅と各自の平均所要時間を取得。一番遠い人の時間が最も短くなる駅を選ぶ。

Agent 3

🌿 実在のお店選び

ホットペッパーの実在店舗とTime Out掲載店から候補を作成。予定時刻に閉まっている店は除外し、混雑度は「推定」と明記。

Agent 4

📝 予約の準備

予約ページ、電話用の台本（ワンタップ発信）、デモ用フォームへのAI自動入力を用意。AIが勝手に電話や予約確定はしない。

🗣️ 発表用スクリプト

「雑談から出発駅を読み取り、駅すぱあとで公平な集合駅を決め、実在のお店を投票で選び、予約の準備までを自動で行います。電話をかけるのは幹事本人です。」

ハッカソン規約遵守 & 技術的工夫

「駅すぱあと」APIのダイヤ情報不使用を徹底

🛡️ 使っているのは時刻表を使わない機能だけ

  • ✅ ダイヤ探索（時刻指定探索）は一切不使用
  • ✅ ekispert_api_search_ranges（平均待ち時間込み）を1回呼ぶだけで全員分の平均所要時間を取得
  • ✅ 「〇〇から」の駅名は ekispert_api_get_stations で照合
  • ✅ 結果はキャッシュし、同じ問い合わせを繰り返さない

⚖️ 公平な集合駅の選び方

①一番遠い人の移動時間が最短 ➔ ②同じなら移動時間の差が最小 ➔ ③それも同じなら平均が最小。

横浜(42分) • 吉祥寺(39分) • 中目黒(40分) • 柏(44分)
➔ 集合駅「秋葉原」：最大44分・差は5分
🗣️ 発表用スクリプト

「時刻指定のダイヤ検索は使っていません。範囲探索を1回呼ぶだけで、全員が行ける駅と各自の平均所要時間が分かります。一番遠い人の負担が最も小さい駅を選びます。」

技術スタック & 認知負荷を下げるUX

アプリ不要 — LINE & Google Cloud

📱 LINE Flex Message

参加・OK・投票はボタン1つ。押した内容はその人の発言として表示され、ボットは必要なときだけ話す（すべて返信なのでプッシュ通数0）。

⚡ GMI Cloud

Gemini 3.5 Flash-Liteで日時・希望を抽出し、候補の理由を一文で説明。1日の上限つきで、止まってもルールで動作。

☁️ Google Cloud で稼働中

Cloud Run（ボット）＋ Firestore（東京）＋ Cloud Run Jobs（Playwrightのフォーム入力エージェント）。使われないときは0台まで縮小。

🗣️ 発表用スクリプト

「アプリのダウンロードもアカウント登録も不要です。いつものLINEグループで、ボタンを押すだけで決まります。」

安心して使える設計

呼ばれるまで読まない、決まったら消す

🔑 招待制

招待コードで認証した人だけが、グループでボットを有効化できる。

🙈 呼ばれるまで読まない

待機中のトークは読まずに破棄。募集中も、参加した人のメッセージだけ。

🧹 決まったら消す

LINEのIDはハッシュ化。チャット本文は検索後、名前と投票は決定時に削除。

🧾 使いすぎない

1グループ1軒・検索3回・7日間。サービス全体にも1日の上限。

🗣️ 発表用スクリプト

「招待制で、呼ばれるまでトークは読みません。お店が決まったら個人の情報は削除し、ボットはグループを退出します。」
