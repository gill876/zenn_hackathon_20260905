Criterion 2: Multi-Step Autonomous Workflow (複数ステップの自律実行)

4 Specialized Autonomous Agents in Harmony

AGENT 1

📅 Schedule Sync

Listens to casual group banter. Extracts participant names, departure stations, and food tastes.

AGENT 2 (EKISPERT)

🚇 Hub Balancer

Queries Ekispert range search to compute the fairest midpoint station within ±5 min travel equality.

AGENT 3

🌿 Spot Discovery

Avoids crowded tourist chains. Discovers calm back-alley venues and hidden gems (穴場).

AGENT 4

📞 Voice Booking

Directly places an AI phone call to non-tech Japanese venues and secures reservations.

🗣️ Speaker Script:
"Our system runs 4 sequential agents: Agent 1 parses the chat, Agent 2 calculates the equal midpoint using Ekispert, Agent 3 curates low-crowd spots, and Agent 4 calls the restaurant directly to book a table."
「システムは4つのエージェントで構成されます。雑談から出発駅を読み取り、駅すぱあとAPIで公平な中間駅を割り出し、穴場を提案し、店舗への電話予約まで自律的に完遂します。」
"System wa 4-tsu no agent de kousei saremasu. Zatsudan kara shuppatsueki wo yomitori, Ekispert API de kouhei na chuukan-eki wo waridashi, anaba wo teian shi, tenpo e no denwa yoyaku made jiritsuteki ni kansui shimasu."
Hackathon Compliance & API Integrity

Strict Compliance: Non-Timetable Usage

🛡️ Strict Hackathon Rule Adherence

We strictly avoid specific timetable/schedule queries (`ダイヤ情報不使用`).

  • Uses ekispert_api_search_ranges (reachable station space)
  • Uses searchType: plain (average transit duration)
  • Balances maximum travel time and variance across all attendees

⚖️ Real Test Result

4 friends coming from Yokohama, Nakameguro, Kichijoji, and Kashiwa:

• Yokohama: 44 mins
• Nakameguro: 39 mins
• Kichijoji: 37 mins
• Kashiwa: 42 mins
➔ Fair Midpoint: Okachimachi / Ueno (±4 min difference!)
🗣️ Speaker Script:
"We strictly adhere to the hackathon's rules by not using timetable searches. Instead, we use topological range searches and average transit times to calculate the fairest hub station in sub-seconds."
「規約に従い、時刻指定ダイヤ探索は使っていません。範囲探索と平均探索のみを用いて、全員の移動時間がほぼ均等になる公平なハブ駅を高速に算出しています。」
