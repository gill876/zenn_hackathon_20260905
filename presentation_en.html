AsobiAgent: Group Outings Without an Organizer

A multi-agent LINE bot that takes a group chat from "where is everyone coming from?" to a fair meeting station (Ekispert), a vote on real venues, and everything needed to book.

🚇 Ekispert MCP

No timetables: one range search gives everyone's average travel time.

💬 LINE Flex UI

No app to install. Joining, confirming and voting are one tap each.

⚡ GMI Cloud (Gemini 3.5 Flash-Lite)

Reads dates and wishes, explains each pick. Falls back to rules if it's unavailable.

Criterion 1: Real-World Problem (現場起点の切実な課題)

Planning Tokyo Outings is Exhausting

😫 30+ Message Chaos

Endless text threads just to figure out who is coming from where and what people want to eat. Nobody wants to be the Kanji (organizer).

⚖️ Unfair Commute Times

One friend travels 50 mins while another travels 10 mins. Agreeing on a central station causes silent friction and resentment.

☕ Tokyo Weekend Over-Tourism

Major hubs like Shibuya and Shinjuku are packed. Groups end up waiting 45+ minutes in line at crowded cafes without reservations.

🗣️ Speaker Script:

「友達とのお出かけは、LINEのやり取りが多く、移動時間の不満も生まれ、結局混雑に巻き込まれます。AsobiAgentはこの幹事負担をゼロにします。」
"Tomodachi to no odekake wa, LINE no yaritori ga ooku, idou jikan no fuman mo umare, kekkyoku konzatsu ni makikomaremasu. AsobiAgent wa kono kanji futan wo zero ni shimasu."
Criterion 2: Multi-Step Autonomous Workflow (複数ステップの自律実行)

4 Agents, Inside the Group Chat

AGENT 1

📅 Who, From Where, When

Reads only the messages of people who joined the plan. Stations are checked against Ekispert's station list; dates and wishes go through the LLM.

AGENT 2 (EKISPERT)

🚇 Fair Meeting Station

One range search returns every station all members can reach, with each person's average minutes. The shortest worst-case trip wins.

AGENT 3

🌿 Real Venues

Real HotPepper venues plus places Time Out has covered. Places closed at the planned time are dropped; crowding is labelled as an estimate.

AGENT 4

📝 Ready to Book

The booking page, a call script with one-tap dialing, and an AI agent that fills a (demo) reservation form. It never calls or books on its own.

🗣️ Speaker Script:
"Four agents work inside the chat: Agent 1 reads where people are coming from, Agent 2 finds the fairest station with Ekispert, Agent 3 picks real venues for the group to vote on, and Agent 4 gets everything ready to book. The organizer makes the call."
「雑談から出発駅を読み取り、駅すぱあとで公平な集合駅を決め、実在のお店を投票で選び、予約の準備までを自動で行います。」
"Zatsudan kara shuppatsu-eki wo yomitori, Ekisupaato de kouhei na shuugou-eki wo kime, jitsuzai no omise wo touhyou de erabi, yoyaku no junbi made wo jidou de okonaimasu."
Hackathon Compliance & API Integrity

Strict Compliance: Non-Timetable Usage

🛡️ Only Timetable-Free Tools

No timetable or departure-time searches (ダイヤ情報不使用).

  • ekispert_api_search_ranges with averaged waits: one call gives every member's average minutes
  • ekispert_api_get_stations confirms that 「〇〇から」 is a real station
  • Results are cached, so repeat questions cost nothing

⚖️ How "Fair" Is Decided

1) shortest worst-case trip, 2) then the smallest gap between members, 3) then the lowest average.

• Yokohama: 42 mins
• Kichijoji: 39 mins
• Nakameguro: 40 mins
• Kashiwa: 44 mins
➔ Meeting station: Akihabara (max 44 min, 5 min gap)
🗣️ Speaker Script:
"We don't use any timetable searches. A single range search tells us every station the whole group can reach and each person's average travel time, so we pick the station where the person with the longest trip has it easiest."
「時刻指定のダイヤ検索は使っていません。範囲探索を1回呼ぶだけで、全員の平均所要時間が分かります。」
"Jikoku shitei no daiya kensaku wa tsukatte imasen. Han'i tansaku wo ikkai yobu dake de, zen'in no heikin shoyou jikan ga wakarimasu."
Criterion 3: Low-Cognitive-Load UX (認知負荷を下げる体験設計)

Embedded in LINE, Running on Google Cloud

📱 LINE Flex Cards

Join, OK and vote are single taps that show up as the person's own message. The bot only speaks when something changes, and only by reply, so it uses no push quota.

⚡ GMI Cloud

Gemini 3.5 Flash-Lite reads dates and wishes and writes a one-line reason per venue. Capped per day; rule-based fallback if it's down.

☁️ Live on Google Cloud

Cloud Run (the bot), Firestore in Tokyo, and a Cloud Run Job running Playwright for the form agent. Scales to zero when idle.

🗣️ Speaker Script:
"No app to download and no account to create. It all happens in the LINE group people already use, one tap at a time."
「アプリのダウンロードもアカウント登録も不要です。いつものLINEグループで、ボタンを押すだけで決まります。」
"Apuri no daunroodo mo akaunto touroku mo fuyou desu. Itsumo no LINE group de, botan wo osu dake de kimarimasu."
Built to Be Trusted (安心して使える設計)

Reads Nothing Until Called, Forgets When Done

🔑 Invite Only

Only people verified with a single-use invite code can switch the bot on in a group.

🙈 Quiet by Default

Idle chat is dropped unread. While planning, only participants' messages are read.

🧹 Deleted at the Decision

LINE IDs are stored only as hashes. Chat text goes after the search; names and votes at the decision.

🧾 Bounded Cost

One venue, three searches and seven days per group, plus daily caps for the whole service.

🗣️ Speaker Script:
"It's invite-only and reads nothing until someone calls it. Once a venue is decided, personal data is deleted and the bot leaves the group."
「招待制で、呼ばれるまでトークは読みません。お店が決まったら個人の情報は削除し、ボットはグループを退出します。」
"Shoutaisei de, yobareru made tooku wa yomimasen. Omise ga kimattara kojin no jouhou wa sakujo shi, botto wa guruupu wo taishutsu shimasu."
